rpython-albert
==============

This rpython driver is based on the rpython script which comes with PyPy/rpython. And updated by Albert, such that it
can run the rpython translator without “installing” .

Typically, a file as ``pypy2.7-v7.3.20-macos_arm64.tar.bz2`` is downloaded, and unpacked. Then it ready to use.

By placing Albert’s version in the .../bin/ dir (replacing the rpython script in it), you can use it by calling that rpython-driver.
