Possible BUGS, in RPy
=====================

buildin.CC_B_ComponentClass
===========================

Instances of this python-class should be generated by PRy, and is used by (f.e.) Elemental/HelloWorld, but looks
**useless**!

That class was used already in `CC-event-sieve.Castle-handCompiled.c` (and `runtime.c`). There, holds relevant info,
including ``.instance_size``, which is used in `CC_Mc_New()`, to alloc memmory for an element/instance.
|BR|
Also the dispatch-table for all methods (``.CC_B_mDispatchTable``) is saved in that structure.
|BR|
And it holds a field ``.interface``, which seams *unused*.


In RPy, ``.instance_size`` and `CC_Mc_New()` are **not** needed, nor used. The (generated/buildin) python class
structures are used for that. The same applies to the dispatch-tables: methods are called via the `$object.$method()`
construct. 






.. tip:: As an experiment is set to a string, and it still runs
         (done in _run/HelloWorld.py; not HelloWorld.rpy)
